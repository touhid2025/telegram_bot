# Vendor/Buyer Report Number Tracker Bot

Telegram বট যা Vendor ও Buyer দিলে সংশ্লিষ্ট রিপোর্ট নাম্বার(গুলো) খুঁজে দেয়। নতুন এন্ট্রি শুধু এডমিন যোগ করতে পারবে।

## ধাপে ধাপে সেটআপ (PC/ল্যাপটপে)

### ১. Python ইনস্টল আছে কিনা যাচাই করুন
টার্মিনাল/কমান্ড প্রম্পটে লিখুন:
```
python --version
```
না থাকলে [python.org](https://www.python.org/downloads/) থেকে ইনস্টল করুন (Windows-এ ইনস্টলের সময় "Add Python to PATH" টিক দিতে ভুলবেন না)।

### ২. বটের জন্য টোকেন নিন
1. Telegram-এ `@BotFather` খুঁজে বের করুন
2. `/newbot` লিখে পাঠান
3. বটের একটা নাম ও ইউজারনেম দিন (ইউজারনেম অবশ্যই `bot` দিয়ে শেষ হতে হবে)
4. একটা টোকেন পাবেন, যেমন: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`

### ৩. নিজের Telegram ID বের করুন
1. Telegram-এ `@userinfobot` খুঁজে বের করুন
2. `/start` চাপুন
3. আপনার User ID দেখাবে (একটা সংখ্যা)

### ৪. ফাইল সেভ করুন
`bot.py`, `requirements.txt`, `README.md` — তিনটা ফাইল একটা ফোল্ডারে (যেমন: `telegram_bot`) রাখুন।

### ৫. লাইব্রেরি ইনস্টল করুন
ফোল্ডারে টার্মিনাল খুলে লিখুন:
```
pip install -r requirements.txt
```

### ৬. bot.py এডিট করুন
`bot.py` ফাইল Notepad/VS Code দিয়ে খুলে উপরের দিকে এই দুই লাইন বদলান:
```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"   # ধাপ ২ থেকে পাওয়া টোকেন বসান
ADMIN_IDS = [123456789]              # ধাপ ৩ থেকে পাওয়া আপনার ID বসান
```
একাধিক এডমিন থাকলে: `ADMIN_IDS = [123456789, 987654321]`

### ৭. বট চালু করুন
```
python bot.py
```
টার্মিনালে "বট চালু হয়েছে..." দেখালে বট চালু হয়ে গেছে।

## কমান্ড তালিকা

| কমান্ড | কে ব্যবহার করতে পারবে | ফরম্যাট | উদাহরণ |
|---|---|---|---|
| `/start` | সবাই | `/start` | — |
| `/find` | সবাই | `/find vendor \| buyer` | `/find ABC Textiles \| XYZ Buyer Ltd` |
| `/add` | শুধু এডমিন | `/add vendor \| buyer \| report_number` | `/add ABC Textiles \| XYZ Buyer Ltd \| INT-2026-00123` |
| `/delete` | শুধু এডমিন | `/delete id` | `/delete 5` |
| `/list` | শুধু এডমিন | `/list` | সর্বশেষ ৫০টি এন্ট্রি দেখায় |

> খেয়াল করুন: vendor, buyer, report_number আলাদা করতে `|` (pipe) চিহ্ন ব্যবহার করা হয়েছে।

## ডেটা কোথায় থাকে?
সব এন্ট্রি `reports.db` নামে একটা SQLite ফাইলে সেভ হয়, যা `bot.py`-এর একই ফোল্ডারে তৈরি হবে। বট বন্ধ করলে বা কম্পিউটার রিস্টার্ট করলেও ডেটা হারাবে না।

## বট ২৪/৭ চালু রাখতে চাইলে
এই সেটআপে বট শুধু ততক্ষণ চালু থাকবে যতক্ষণ আপনার PC-তে `python bot.py` চলমান থাকবে এবং PC অন থাকবে। সবসময় চালু রাখতে চাইলে:
- Railway.app বা PythonAnywhere-এর মতো ফ্রি ক্লাউড হোস্টিং ব্যবহার করতে পারেন
- অথবা PC-কেই সবসময় চালু রাখতে পারেন
